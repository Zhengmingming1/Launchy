  - 窗口标题和「给任务起个名字」「① 做什么？」「② 什么时候做？」标为标题，读屏用户可以用转子按标题跳转。

### 2026-11-09 · 体验：任务「下次什么时候运行」一目了然

- **改了什么**：

  - 新建 / 修改任务窗口：底部的一句话总结下面多一行灰色小字，说清楚保存后什么时候第一次运行——「每隔一段时间」：保存后不会马上运行，大约 N 分钟后第一次（想试试可以右键「立即运行一次」）；「每天固定时间」：第一次会在今天 / 明天 HH:MM 运行，到点时电脑在睡眠会在醒来后补上；「开机时」：保存后会马上运行一次。修改一个暂停中的任务时，改为提示「恢复后才会按计划运行」。

- **安全**：只改显示，不改任务的 plist 和运行方式；苹果系统服务不涉及。

### 2026-11-06 · 安全体验：标出「最近新增」的自启动项

### 2026-11-03 · 报错文案 / 视觉：运行记录直接标出「出错的那一行」

- **改了什么**：
  - `LogDiagnosis` 新增 `problem(in:action:)`，除了大白话原因，还返回运行记录里出错的那一行（`diagnose` 改为复用它，行为不变）。
  - 「查看运行记录」窗口：上次运行失败且认出了原因时，顶部用橙色提示条写出原因（和列表里那句一样），并把日志里对应的那一行标橙、加粗、左边加一条橙线，打开时自动滚到它（同样的错误出现多次时取最后一次）；认不出来或任务没失败时，打开就滚到最底下，直接看到最新的输出（以前停在最上面的旧内容）。
  - 新增「拷贝全部」按钮，方便把运行记录发给别人帮忙看（逐行显示后，跨行选中不如以前方便，用这个补上）。
  - 读运行记录改成只读文件末尾 16 KB（以前把整个日志读进内存再截 6000 字），日志很大时打开更快、更省内存；从中间截断时去掉半截的第一行。逐行用 `LazyVStack` 显示，只渲染看得到的部分。
  - VoiceOver：提示条合并成一句读出，出错的那一行会读成「出错的一行：……」。

- **README / 截图**：界面外观没有变化，无需更新截图；README 可以在特色里加一句「支持 VoiceOver 读屏」。

### 2026-10-22 · 新功能 / 安全体验：标出「残留」自启动项

- **改了什么**：扫描第三方自启动项时检查 plist 里写的程序文件是否还在。程序已被删除的项：
  - 列表状态显示橙色「⚠️ 程序已删除」；
  - 「开机自启动」页顶部出现提示条：「发现 N 个残留项……可以放心关掉」；
  - 详情页顶部用大白话说明原因和处理方法（关掉，或在访达中把配置文件移到废纸篓）。
- **为什么**：软件卸载后经常只删了 .app，留下 LaunchAgent/Daemon，开机时反复报错、拖慢登录。普通用户看不出哪些能关，现在一眼就知道。
- **安全**：只检查第三方服务，苹果 `/System/Library` 下的服务完全不参与；只认绝对路径，且只有系统明确返回「文件不存在」（ENOENT/ENOTDIR）才标记，没权限读取一律当作存在，宁可漏报不误报；不自动删除任何东西。
- **参考**：[alienator88/Pearcleaner](https://github.com/alienator88/Pearcleaner)（孤立文件 / 残留文件搜索的思路）、[objective-see/KnockKnock](https://github.com/objective-see/KnockKnock)（列出持久化项并标出可疑项）。只借鉴想法，没有使用代码。
- **README / 截图**：README「开机自启动」一节可以加一句「会标出软件卸载后留下的残留项」；`docs/images/mockup-startup.png` 没有体现残留提示条，周五发版时可以顺手更新。
