- 「我的任务」会告诉你任务跑得怎么样了：每一行下面多了一行小字，显示上次运行成功还是失败、启用以来跑了几次；失败时用大白话说原因，比如「脚本没有执行权限」「脚本里有找不到的命令」
- 任务出问题时直接给你修的办法：要打开的文件被移走或删掉了，会显示橙色「找不到文件」和「重新选择…」按钮；运行失败的任务旁边有「查看运行记录」按钮，一点就能看到报错
- 侧边栏会提醒你哪里需要处理：「我的任务」有任务出错、「开机自启动」有还开着的残留项时，名字旁边会出现一个橙色感叹号，鼠标停上去能看到原因
- 「开机自启动」页加了「全部 / 已开启 / 已停用 / 残留」筛选，后面带数量；残留提示条上的「只看残留项」一点就能切过去
- 「开机自启动」列表会自动刷新：新装或卸载的软件增删了自启动项，列表马上跟着变，不用再手动点「刷新」
- 支持 VoiceOver 读屏：每一行读成「名字，状态」，开关、修改、立即运行、查看运行记录等操作都能在 VoiceOver 的操作菜单里找到
