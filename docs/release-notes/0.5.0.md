- 任务什么时候跑一目了然：「每天固定时间」的任务在「我的任务」里会显示「下次：今天 21:00」「下次：明天 09:00」，每分钟自动更新
- 新建或修改任务时，会预先告诉你保存后第一次什么时候运行：每隔一段时间的任务不会马上跑、开机时的任务会马上跑一次、睡眠错过的每日任务醒来会补上
- 保存按钮变灰时，旁边会直接用小字写出「还差一步」（比如还没选文件、间隔要大于 0），不用对着灰按钮猜
- 「开机自启动」会标出最近 7 天新冒出来的自启动项：蓝色小字提醒是什么时候发现的，附「知道了」按钮；多了一个「最近新增」筛选，有好几个时可以「全部知道了」一次确认（只是不再提醒，不会关掉它们）
- 侧边栏「开机自启动」旁边出现蓝色小圆点，说明有最近新增的自启动项，点进去直接看到它们
- 自启动项详情页新增「谁做的」：读取程序签名，用大白话说出是苹果、App Store、苹果认证的开发者（显示公司名），还是未签名 / 签名无效
- 任务失败时报错更好懂：能认出「命令找不到 / 没权限 / 文件不存在 / 隐私保护拦截」等常见问题，说出是哪条命令、哪个文件；运行记录窗口把出错的那一行标橙并自动滚过去，还能「拷贝全部」
- 「我的任务」支持键盘：选中后回车修改、空格暂停或恢复、删除键删除（会先确认）；右键菜单也能暂停 / 恢复
- 「我的任务」在任务文件变化、切回 Launchy 时自动刷新，不再显示过时的运行结果
- 新建 / 修改任务窗口支持 VoiceOver：会读出哪个选项已选择、每个输入框的名字，以及保存按钮为什么不能点
