- 软件卸载后留下的残留自启动配置，可以先备份再移到废纸篓：只处理程序已经不在了的第三方项，不会永久删除；涉及 /Library 时会要一次密码。移走之后，访达会打开废纸篓并选中这些文件，方便当场确认或拖回去
- 详情页「谁做的」对认证开发者的程序会再补一句有没有经过苹果公证：已公证会说明苹果扫描过；查不到只用灰色说明，不吓人（后台检查，不强制联网）
- 下次打开会记住上次看的是「我的任务」「开机自启动」还是「系统服务」，直接回到那里；第一次使用仍从「我的任务」开始
- 运行记录认出是隐私保护拦住，或任务要打开的文件找不到了，会在橙色说明旁边直接给出「打开系统设置」或「重新选择…」，不用自己去翻
- 「每隔一段时间」设成少于 5 分钟时，会在间隔下面用橙色小字提醒（打开程序会反复弹出、打开文件会打断手上的事、脚本更费电且没跑完会跳过），只提醒，不阻止保存
- 新建或修改任务时，点看起来灰掉的「创建 / 保存」按钮，会让还没选文件或间隔没填对的那一行闪一下描边，把人带到要补的地方
