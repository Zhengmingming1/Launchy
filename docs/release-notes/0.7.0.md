- 清理残留的自启动配置时如果点错了，现在可以在软件里直接还原：「开机自启动」页面上方会出现「从备份还原…」，选中那一项放回原处就行。只放回文件，不会自动开启；涉及 /Library 时可能要输一次密码
- 服务详情里「技术信息」的每一行都能一键拷贝，另有「拷贝全部技术信息」，想请别人帮忙看问题时更方便
- 新建或修改任务时，在「分钟 / 小时」之间切换，间隔数字会一起换算（60 分钟 → 1 小时，不再变成 60 小时）；换不整的会用灰色小字提示
- 服务详情、编辑服务和还原备份窗口整理了 VoiceOver 的读法：小节标为标题，状态读成「状态：运行中」，输入框都有名字
- 同一个软件的服务共用一张图标，并缩成 128×128 的小图缓存，服务多的时候占用的内存更少
